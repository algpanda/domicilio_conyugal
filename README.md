# Casa en orden

Pequeña aplicación en español para organizar tareas del hogar y la lista de la compra. Se puede abrir directamente en el navegador: no requiere instalación ni compilación.

## Uso

Abre `index.html` en un navegador e introduce el código temporal **1210**. Las tareas y los artículos de la compra se guardan en el almacenamiento local de ese navegador.

## Importante sobre el código

El acceso con código está implementado en JavaScript del lado del navegador y sirve como pantalla de privacidad casual, no como autenticación segura: cualquiera con acceso al código fuente puede verlo y saltarse la pantalla. No guardes información sensible aquí. Para restringir el acceso de verdad, hace falta una validación en un servidor.
